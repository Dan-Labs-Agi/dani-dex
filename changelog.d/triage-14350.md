### Fixed

- On a Mac, you can now install an update when macOS runs dani-dex from a temporary copy while dani-dex is already in the Applications folder. Before, dani-dex did not install the update and told you to move it in Finder, and this did not always help. Now dani-dex checks the signature of the copy in the Applications folder and restarts from it. Then you can install the update from there.
